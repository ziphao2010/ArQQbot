# 人格蒸馏插件

把「人格蒸馏」搬到 QQ 里：用人格语料蒸馏出人格档案，并带上分层长期记忆，让 TA 在单聊里持续记得你、记得你们聊过的事。

底层记忆引擎在 `packages/persona-core`，插件只负责 QQ 命令与消息收发。

## 三层记忆

| 层 | 内容 | 生成方式 |
| --- | --- | --- |
| 个人记忆（全局） | 人格自己的经历、偏好、口头禅、做事方式 | 首次语料蒸馏 + 每次记忆整理 |
| 会话记忆 | 当前会话最近聊天 + 滚动摘要 | 每轮追加，达到间隔后压缩成摘要 |
| 用户印象 | TA 对你的认识、关系变化、关于你的稳定事实 | 首次语料导入 + 跨会话持续更新 |

第一次聊天使用的记忆来自你导入的聊天记录/语料；之后每聊 `memoryEveryTurns` 轮，会调用模型整理一次记忆与印象。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/蒸馏 名字 [语料]` | 开始蒸馏，进入语料收集模式 |
| `/完成` | 用已收集的语料提炼人格与初始记忆 |
| `/取消` | 放弃本次蒸馏 |
| `/用 名字` | 当前会话切换为该人格 |
| `/退出` | 退出人格对话 |
| `/人格列表` | 查看已蒸馏的人格与记忆条数 |
| `/人格查看 名字` | 查看人格档案 |
| `/人格删除 名字` | 删除人格及其记忆 |
| `/记忆 [名字]` | 查看个人记忆、对你的印象、会话摘要 |
| `/记住 内容` | 手动写入一条关于你的长期记忆 |
| `/忘记 关键词` | 删除匹配的记忆 |
| `/重置` | 清空当前会话聊天记忆（长期印象保留） |
| `/导出 [名字]` | 导出人格包 JSON（可导入 CLI 或另一个实例） |
| `/导入 {JSON}` | 导入人格包 |
| `/帮助` | 用法说明 |

命令前缀可配置，默认 `/`。

## 配置

| 字段 | 说明 |
| --- | --- |
| `baseUrl` | OpenAI 兼容接口基础地址，默认 `https://api.deepseek.com/v1` |
| `apiKey` | 模型服务密钥（敏感字段） |
| `model` | 模型名称，默认 `deepseek-chat` |
| `temperature` | 采样温度，默认 0.7 |
| `ownerName` | 你在人格眼中的称呼；留空使用 QQ 昵称 |
| `immersion` | `strong`（默认，不自称 AI）或 `balanced` |
| `maxReplyLength` | 单条回复字数上限，默认 600 |
| `maxRecentMessages` | 直接进入提示词的最近消息条数，默认 12 |
| `memoryEnabled` | 是否启用长期记忆整理 |
| `memoryEveryTurns` | 每多少轮整理一次记忆与印象，默认 3 |
| `retrievalTopK` | 每轮注入的相关记忆条数，默认 8 |
| `contextBudgetChars` | 人格上下文预算，超限自动裁剪召回记忆 |
| `commandPrefix` | 命令前缀，默认 `/` |

## 运行与边界

- 需要 Node.js 22+ 与 ArQQbot 0.1+。
- 群聊只有被 @ 时才收到消息；如果只想自己用，建议单聊。
- 语料上限 20000 字；模型生成的人格与记忆可能有偏差，可用 `/记住`、`/忘记` 纠正。
- 记忆检索为本地 JSON + 关键词/重要度/新近度加权，不依赖向量库。
- 插件只在收到消息时被动回复，不发送主动消息。

## 数据与权限

- 使用 `ctx.qq`（发送文本回复）、`ctx.storage`（保存人格与记忆）、`ctx.logger`。
- 存储键：`persona:db`（人格、会话、印象）。
- 发送给模型的内容：语料、人格档案、召回的长期记忆、最近聊天；不会读取 QQ 凭据或其他实例数据。
- 日志不写入语料正文与 API Key。
